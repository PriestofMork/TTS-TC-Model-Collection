TC Miniatures – Warband Code

Turns a Trench Companion warband into a short code for the TC Miniatures spawner in Tabletop Simulator. Everything happens in your browser: nothing is uploaded or saved.

  1. In Trench Companion, copy your warband's TTS export.
  2. Paste it below and press Make code.
  3. Press Copy code, then paste the code into the spawner's import box in TTS.
